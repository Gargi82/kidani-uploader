Privacy Policy

Last updated: 19 November 2026

KidAni Uploader ("the app") is a private tool used only by the owner of the YouTube channel Baby Dino World to upload that channel's own videos. It is not offered to other users.

YouTube API Services

The app uses the YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the app accesses

The app asks for one permission: youtube.upload, to upload videos and set their thumbnails on the authorized channel. It sends Google only the video file, its thumbnail and its title, description, tags, audience ("made for kids") and publishing settings. It does not read viewers' data, comments, analytics or any other account information.

Storage

The OAuth access token is stored only on the channel owner's computer, so uploads can run without signing in each time. The app has no server, collects no personal data, uses no cookies or tracking, and shares no data with third parties.

Revoking access

Access can be revoked at any time at Google Account → Security → Third-party access. Deleting the stored token file removes the app's access from the computer as well.
