Privacy Policy

Last updated: 19 November 2026

KidAni Uploader ("the app") is a private tool used only by the owner of the YouTube channel Baby Dino World to upload that channel's own videos. It is not offered to other users.

YouTube API Services

The app uses the YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the app accesses and why

The app asks for one permission: youtube.upload, to upload videos and set their thumbnails on the authorized channel. It sends Google only the video file, its thumbnail and its title, description, tags, audience ("made for kids") and publishing settings, all created by the channel owner. It does not read viewers' data, comments, analytics or any other account information.

What is stored, where, and how it is shared

The only data the app stores is the OAuth access and refresh token, kept in a file on the channel owner's computer so uploads can run without signing in each time. The app has no server, collects no personal data, uses no cookies, analytics or tracking, and does not share, sell or transfer any data to third parties.

Revoking access

Access can be revoked at any time on the Google security settings page (Google Account → Security → Third-party apps with account access).

Data deletion

To delete all data the app holds, delete the token file (secrets/token.json) from the computer and revoke access as described above. After revocation the token can no longer be used. The app keeps no other copy of any data, so nothing remains after these steps. Requests about data can also be sent to the contact address below and will be handled within 7 days.
